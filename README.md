# Fase 5 - Evaluación Final POA

## Problema 5: Cálculo de horas trabajadas semanalmente

Este repositorio contiene la solución en Python del Problema 5 del curso Fundamentos de Programación.

El programa utiliza una matriz para registrar las horas trabajadas por un equipo durante la semana. Luego calcula el total de horas semanales por cada recurso y clasifica la jornada laboral como "Sobretiempo" o "Horario Estándar o inferior".
